Privacy policy

How Google Drive data is handled

Effective August 29, 2026

Scope

Personal Paper Reader is a private, non-commercial application operated for a single user. This policy describes how it handles data obtained through Google Drive.

Data accessed

The application may access file names, metadata, folder structure, and file contents needed to find and process research PDFs. It may create, rename, move, or upload files only to deliver the paper-management workflow configured by the user.

Purpose

Google Drive data is used to detect new papers, prevent duplicate imports, organize source PDFs, and generate private reading exports. It is not used for advertising, profiling, or unrelated purposes.

Storage and retention

OAuth credentials and working copies are stored on private systems controlled by the user. Files and processing records are retained only as needed for the personal workflow and can be removed by the user. Access can be revoked at any time from the Google Account third-party connections page.

Sharing and transfer

Google user data is not sold, rented, or shared for advertising. No Google Drive content is provided to an AI service unless the user separately enables and approves such a feature under an updated disclosure.

Google API Limited Use

Personal Paper Reader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Security

Access credentials are restricted to the private server process, and the application interface is protected by access controls. No security method can guarantee absolute protection, but access is limited to what is needed for this private workflow.

Contact and deletion requests

The sole user can revoke access through their Google Account, delete files from Google Drive, and contact the operator through the support email shown on the Google OAuth consent screen.
